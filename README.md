# 养老金估算器

该网站是帮助你估算养老金的小小工具，毕竟现在全员社保了

退休后每月大概能领多少养老金？选好预计领养老金的地方，填入缴费年限、平时按多少钱交养老保险，以及预计退休年龄，就能看到每月的估算金额。页面会分别列出基础养老金和个人账户养老金，方便你看懂总额是怎么来的。

适合通过单位参保的职工，也适合自己缴纳职工养老保险的自由职业者和无雇工个体工商户。

## 怎么用

1. **选参保方式和退休地。** 页面会显示当地算养老金用的参考金额和对应年份。部分地区需要手动填写。
2. **填自己的缴费情况。** 可以在社保缴费记录里找到“缴费基数”。例如一直按每月 6000 元缴费，这里就填 6000 元。
3. **查看估算结果。** 不清楚退休时个人账户里会有多少钱，可以让网页估算；已有预计余额，也可以自己填写。点击“更新估算结果”即可查看。

## 本地运行

下载 `index.html`，用浏览器打开即可。所有计算都在本机浏览器中完成，填写的信息不会上传或保存。

**测试仅供娱乐** 各地区参考数据的年份可能不同，估算结果仅包含基础养老金和个人账户养老金，实际领取金额以当地社保经办机构核定为准。
